# chemlab-2.0
chemlab-2 project Build a complete, production-ready Android app called ChemLab 2.0.

The app is an offline-first Cambridge IGCSE Chemistry learning simulator for students.

Requirements:
- Native Android project using Java and Gradle.
- Package name: com.chemlab.app
- minSdk: 23
- targetSdk: 35
- Modern premium dark laboratory UI.
- Deep black/dark-green background.
- Neon-green chemistry accents.
- Glass-style cards and smooth animations.
- Home dashboard with Chemistry Topics, Experiments, Simulator, Quiz, and Progress.
- Include chemistry content suitable for Cambridge IGCSE level.
- Include realistic interactive simulations where appropriate.
- Show observable reaction changes such as colour changes, gas formation, precipitates, temperature changes, and pH changes.
- Work offline after installation.
- Do not require a server or internet connection for the core learning features.
- Include search for topics.
- Include quizzes with scoring.
- Include progress tracking stored locally.
- Add a professional ChemLab launcher icon.
- Make all screens responsive to different Android screen sizes.
- Follow Android security and modern UI best practices.
- Do not leave placeholder screens or TODO sections.

Most importantly, create a COMPLETE BUILDABLE Android Studio project.

Include:
- settings.gradle
- build.gradle
- app/build.gradle
- gradle.properties
- gradlew
- gradlew.bat
- gradle/wrapper/gradle-wrapper.properties
- gradle/wrapper/gradle-wrapper.jar
- AndroidManifest.xml
- all Java source files
- all layouts/resources
- launcher icons
- all required assets

Make sure the project builds successfully with:

./gradlew assembleDebug
